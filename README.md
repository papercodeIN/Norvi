## About

Example projects for **NORVI industrial controllers** — ESP32-based HMI and GSM controllers built for industrial automation.

## Contents

| Folder | What's inside |
|--------|---------------|
| `ESP32 Industrial HMI/` | `Analog_Input_Example` and `TouchPoint_Tracker` Arduino projects + required `libraries.7z` |
| `GSM AE04-V-G Industrial Controller/` | Code and guides for the GSM AE04-V-G controller |

## Getting Started

1. Extract `libraries.7z` into your Arduino `libraries` folder
2. Open one of the projects listed above
3. Select the matching NORVI/ESP32 board and upload

📺 Video walkthroughs are on our [YouTube channel](https://www.youtube.com/@Fusion_Automate).
